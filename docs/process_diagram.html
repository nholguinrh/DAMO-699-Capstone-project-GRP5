Yield Curve & Monetary Policy Analytics Process

An interactive architectural blueprint illustrating the 5-stage data engineering, econometric modeling, deep learning, and analytical evaluation pipeline using Bank of Canada macro-financial data.

✨ Click any card for detailed specifications
Stage 01
Data Engineering & Medallion Pipeline
Extracts raw macro-financial series via API, applies temporal alignment, and engineers econometric features.
Python Valet API Pandas Medallion
📦 Bronze Layer
Raw API Ingestion
Fetches daily BoC policy rates, 1Y–10Y bond yields, USD/CAD exchange rates, and monthly CPI via REST API with exponential back-off.
Input: BoC Valet REST Raw JSON
🧹 Silver Layer
Temporal Alignment & Cleaning
Aligns calendar dates, handles statutory holiday mismatches via ffill, and merges monthly CPI using pandas merge_asof.
Input: Raw JSON Clean DataFrame
⚡ Gold Layer
Feature Construction
Engineers 10Y-2Y yield spreads (recession indicator), CA-US spreads, 20/60-day rolling volatility, and BoC policy announcement indicators.
Input: Clean DataFrame Feature Matrix
Stage 02
Time-Series Diagnostics
Verifies statistical properties, tests for non-stationarity, applies differences, and screens for cointegration.
Statsmodels ADF Test Johansen Stationarity
📈 Stationarity
ADF Unit-Root Testing
Executes Augmented Dickey-Fuller tests to determine unit roots and unit differencing requirements for each series.
Input: Gold Matrix p-values / I(d)
🔄 Transforms
Stationary Transformations
Applies basis-point first-differencing (Δy_t) to yields and log-differencing (Δln(x_t)) to USD/CAD and CPI to prevent spurious regressions.
Input: Raw Levels Stationary Series
🔗 Equilibrium
Johansen Cointegration
Tests for long-run equilibrium relationships (r ≥ 1) among level series to select between VAR and VECM model specifications.
Input: Level Series Trace / Max-Eigen
Stage 03
Econometric & Deep Learning Modeling
Estimates benchmark ARIMA, multivariate VAR/VECM systems, and nonlinear LSTM neural networks with SHAP interpretability.
Auto-ARIMA VAR/VECM PyTorch/Keras SHAP
🎯 Univariate
Auto-ARIMA Baseline
Automated Box-Jenkins selection of optimal (p,d,q) parameters guided by AIC/BIC minimization to isolate pure autocorrelation signals.
Input: Yield Spread Univariate Baseline
⚙️ Multivariate
VAR / VECM System
Models interdependencies between policy rate, yields, USD/CAD, and CPI. Generates IRFs, FEVD, and Granger causality tests.
Input: Multi-series IRF / FEVD Outputs
🧠 Deep Learning
LSTM + SHAP Model
Single-layer LSTM with dropout, early stopping, and rolling-window CV. Computes SHAP values to explain feature contributions.
Input: Gold Window Nonlinear Forecasts
Stage 04
Model Comparison & Evaluation
Evaluates out-of-sample forecast accuracy across multiple horizons and validates superiority via statistical tests.
RMSE / MAE Diebold-Mariano Multi-Horizon Naïve Floor
📅 Horizons
Multi-Step Forecasting
Generates out-of-sample predictions across 1-day, 5-day (1-week), and 20-day (1-month) forecasting horizons.
Input: Test Windows Forecast Matrices
📊 Error Metrics
RMSE & MAE Assessment
Quantifies prediction accuracy against actual yield curve observations, benchmarking all candidate models against a Naïve Random Walk floor.
Input: Predictions Error Metrics
⚖️ Hypothesis Test
Diebold-Mariano Test
Executes formal hypothesis testing to confirm whether differences in forecast accuracy between VAR/VECM, LSTM, and ARIMA are statistically significant.
Input: Forecast Errors DM Test Statistics
Stage 05
Analytics Delivery & Dashboard
Translates technical findings into interactive Power BI dashboards, stakeholder reports, and academic capstone deliverables.
Power BI Report Presentation Poster
💻 Dashboard
Power BI Interactive App
Interactive yield curve dynamic visualizer, scenario simulation, macroeconomic transmission view, and model leaderboard.
Input: Model Outputs Power BI (.pbix)
📄 Capstones
Final Report & Presentation
Comprehensive peer-reviewed capstone report, presentation slide deck, academic poster, and reflective learning paper.
Input: Project Synthesis PDF / Slides
